# Layout Templates

Complete layout clipboard templates. Paste to **Project Bar → Layouts**.

## Structure Overview

```json
{
  "is-c3-clipboard-data": true,
  "type": "layouts",
  "families": [],
  "object-types": [...],    // Object definitions with imageData indices
  "items": [{
    "name": "Layout 1",
    "layers": [...],
    "width": 1280,
    "height": 720,
    "eventSheet": "Event sheet 1"
  }],
  "imageData": [...]        // Base64 PNG images
}
```
